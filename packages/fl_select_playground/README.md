# fl_select Playground

Live-preview widgets such as `SelectView` / `PopupSelectButton` / `PopupSelectBar` inside a phone frame,
and dynamically tweak behavioral and visual parameters through a control panel.
It ships with a language-agnostic sample filter dataset
(see `lib/entry_repository.dart`) for demonstration purposes.

## Run

```sh
cd packages/fl_select_playground
flutter pub get
flutter run
```
